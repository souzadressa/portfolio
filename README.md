# Meu primeiro portfólio

Portfólio pessoal desenvolvido como desafio do **Programa Trilhas**, na trilha de Desenvolvimento Front-end. A página apresenta meu perfil e reúne meus projetos e certificados.

🔗 **Acesse o site:** https://souzadressa.github.io/portfolio/

## Páginas

- **Início:** foto, nome, uma breve descrição e os botões de navegação.
- **Sobre mim:** um pouco da minha trajetória, dos meus interesses em tecnologia e dos meus objetivos.
- **Projetos:** cards com imagem, descrição e links para o site e o código de cada projeto.
- **Certificados:** cards com os certificados que conquistei, com acesso ao arquivo em PDF.
